02 / COMPUTER ARCHITECTURE

gem5 × Gshare

분기 예측기 비교 실험

종합설계 팀 프로젝트 · 2025C++ / gem5 / RISC-V

gem5의 RISC-V O3CPU 환경에서 Gshare 인덱스 연산을 바꾸고, 워크로드에 따른 MPKI와 IPC 변화를 비교한 종합설계 팀 프로젝트입니다.

인덱스 연산을 바꾸면 분기 예측과 실행 성능은 어떻게 달라질까?
01

문제

분기 주소와 전역 히스토리를 결합하는 방식은 테이블 인덱스에 영향을 줍니다. 다른 연산을 사용했을 때 결과가 어떻게 달라지는지 비교했습니다.

02

비교한 조건

XOR·OR·AND·XNOR를 비교 대상으로 두고, 예측 테이블과 카운터 등의 조건을 유지했습니다. 그래프 워크로드에서 분기 예측 실패와 실행 성능 지표를 함께 살폈습니다.

03

관찰

워크로드에 따라 MPKI와 IPC의 변화가 달랐습니다. 하나의 연산이 항상 우월하다는 결론보다, 입력 특성과 예측 방식의 관계를 해석하는 과정이 중요했습니다.

04

이어지는 관심

이 실험은 프로그램의 특성과 하드웨어 정책을 함께 봐야 한다는 관심으로 이어졌습니다. 지금은 메모리 시스템과 데이터 이동이 실행 효율에 미치는 영향을 더 공부하고 있습니다.

작업 범위와 근거

팀 보고서와 학습 기록을 바탕으로 정리했습니다. 팀 전체의 구현을 개인 단독 성과로 표현하지 않았으며, 원시 로그를 재검증하지 않은 개선율은 싣지 않았습니다.

관련 자료

종합설계 팀 보고서에 근거한 요약입니다. 현재 공개된 원문 링크는 없습니다.
