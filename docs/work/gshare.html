Gshare in gem5

Comparing branch predictor indexing

Team capstone · 2025C++ · gem5 · RISC-V

We compared XOR, OR, AND, and XNOR indexing in a Gshare predictor on gem5's RISC-V O3CPU.

Experiment

We kept the prediction table and counter configuration fixed and ran graph workloads. We compared branch mispredictions per thousand instructions (MPKI) alongside instructions per cycle (IPC).

Takeaway

The results depended on the workload. Comparing MPKI and IPC together helped us see how changes in prediction behavior related to execution performance.

Based on our course report, which is not publicly available.
