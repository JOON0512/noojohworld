Zynq board labs

Interrupts, memory, and device drivers

Coursework · 2026C · Zynq · MMIO

Embedded systems coursework on a Zynq board, using the supplied IP, BSP, and examples.

Exercises

I worked with button interrupts, LED patterns, BRAM, and a TFT-LCD. Interrupt handlers updated state, while the main loop handled output. Other exercises used memory-mapped I/O and a character device driver to connect user programs to the board.

Observation

A busy-wait in the output loop can affect responsiveness even when interrupts are handled correctly. Following the whole path from input to output made that distinction easier to see.
