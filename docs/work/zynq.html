04 / EMBEDDED SYSTEMS

Zynq board labs

하드웨어와 소프트웨어의 경계

임베디드시스템 수업 실습 · 2026C / Zynq / MMIO

Zynq 보드에서 버튼 인터럽트, LED, BRAM, TFT-LCD와 문자 장치 드라이버를 다루며 입력부터 출력까지의 경로를 연결한 실습입니다.

하드웨어의 이벤트는 어떻게 소프트웨어의 상태와 출력으로 이어질까?
01

이벤트와 상태

인터럽트 처리 루틴에서 상태를 갱신하고, main loop에서 LED 패턴을 처리하는 구조를 실습했습니다. 이벤트 수신과 출력 동작을 나누어 읽는 데 초점을 맞췄습니다.

02

메모리와 장치

제공된 IP와 BSP를 바탕으로 BRAM과 TFT-LCD를 제어하고, MMIO와 문자 장치 드라이버를 통해 사용자 프로그램과 하드웨어가 만나는 경로를 학습했습니다.

03

관찰한 제약

출력 루프의 busy-wait가 반응성에 미칠 수 있는 영향을 살폈습니다. 값이 쓰였다는 사실과 기대한 시점에 장치가 반응한다는 사실을 구분하는 경험이었습니다.

04

배운 점

인터럽트·메모리·드라이버를 따로 외우기보다 하나의 데이터 경로로 이해하게 되었습니다. 실행 흐름을 추적하는 관점이 운영체제 실습과도 연결됐습니다.

작업 범위와 근거

수업 제공 하드웨어·IP·BSP 및 예제를 바탕으로 한 실습입니다. Zynq SoC나 모든 IP를 독자 설계한 경험으로 표현하지 않습니다.
