proc-lens

A Linux process snapshot module

Personal projectC · Linux · QEMU

A Linux kernel module that periodically collects process information and keeps a snapshot stable for each open file.

How it works

A delayed_work task collects process data. Reference counting and locking manage object lifetimes, while each open file retains its snapshot even when a newer one is published.

Checks

The repository documents QEMU checks for partial reads, seek, concurrent readers, process creation and exit, and 50 load/read/unload cycles. The test environment is Ubuntu Linux 6.8.0-147-generic on x86-64.

Limits

A stable snapshot does not mean every field was captured at the same instant: RSS and scheduler values can change during collection. KASAN, lockdep, and allocation-failure injection have not been tested.
