proc-lens

Linux 프로세스 관찰 도구

개인 학습 프로젝트 · 공개 코드C / Linux / QEMU

Linux의 프로세스 정보를 주기적으로 수집하고, 파일을 열어 읽는 동안 하나의 스냅샷을 유지하는 커널 모듈입니다.

프로세스는 계속 바뀌는데, 읽는 도중의 데이터는 어떻게 유지할까?
01

문제

프로세스 생성·종료와 데이터 조회는 동시에 일어납니다. 정보를 출력하는 기능뿐 아니라, 수집한 객체와 읽는 데이터의 수명을 다루는 것이 핵심입니다.

02

구현의 초점

delayed_work로 수집을 반복하고, 참조 수명과 잠금을 관리합니다. 새 스냅샷을 교체하더라도 열린 파일에서는 해당 세대를 계속 읽도록 구성했습니다.

03

검증 기록

공개 저장소에는 Linux 6.8 / x86-64 QEMU 환경에서 부분 읽기와 seek, 동시 조회, 프로세스 생성·종료, 50회 load/read/unload를 검사한 절차가 있습니다.

04

배운 점

관찰 도구의 출력도 하나의 동시성 문제입니다. “파일을 읽는 동안 일관됨”과 “모든 필드가 정확히 같은 순간의 값임”은 다릅니다. RSS와 스케줄러 값은 수집 중에도 변할 수 있습니다.

작업 범위와 근거

검증 범위: Ubuntu Linux 6.8.0-147-generic / x86-64. KASAN·lockdep·메모리 부족 주입은 아직 검사하지 않았습니다.
