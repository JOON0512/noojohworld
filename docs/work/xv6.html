xv6-riscv labs

Scheduling, memory, and threads

Coursework · 2024C · RISC-V · QEMU

Operating systems coursework built on MIT xv6-riscv and the course starter code.

Exercises

The assignments cover shell behavior, system calls, stride scheduling, copy-on-write, memory allocation, and threads. They helped me trace a request from user code into the kernel and follow how scheduling and memory policies affect execution.

Testing

The repository includes assignment code and run instructions. The documented checks use one CPU; multicore synchronization and scheduling fairness need separate verification.
