03 / OPERATING SYSTEMS

xv6-riscv labs

스케줄링·메모리·스레드 실습

운영체제론 수업 실습 · 2024C / RISC-V / QEMU

MIT xv6-riscv와 수업 제공 코드를 바탕으로 셸, 시스템콜, 스케줄러, 메모리와 스레드를 확장하며 운영체제의 실행 흐름을 학습했습니다.

정책 하나의 변화가 프로세스의 실행과 메모리에 어떻게 이어질까?
01

실습의 범위

셸과 시스템콜에서 시작해 stride 스케줄링, Copy-on-Write와 메모리 할당, 스레드까지 단계별 과제를 진행했습니다.

02

구현을 읽는 관점

시스템콜이 사용자 코드에서 커널로 들어오는 경로, 스케줄러가 다음 실행 대상을 고르는 과정, 페이지를 공유하다 쓰는 시점에 분리하는 동작을 연결해 살폈습니다.

03

공개 기록

저장소에서 과제별 구현과 실행 안내를 확인할 수 있습니다. 공개 README의 검사 범위는 단일 CPU이며, 다중 CPU 동기화와 공정성 검증은 별도 과제입니다.

04

학습에서 설명으로

운영체제론 튜터링 경험과 함께, 개념을 코드의 동작에 연결해 설명하는 기반이 된 작업입니다.

작업 범위와 근거

MIT xv6 및 수업 골격 코드 기반의 학습 프로젝트입니다. 운영체제 전체를 처음부터 만든 프로젝트는 아닙니다.
